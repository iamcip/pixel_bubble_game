## 目前方向

暖光、自然童話、清楚像素塊與簡單可辨識的泡泡。減少細密材質、碎花與草點；夢幻感集中在少量發光植物。地下與地表角色維持接近的顯示尺度，互動資源須容易辨識。

概念圖展示發展後的生活情境。正式開局仍以規格書為準：五隻泡泡在洞外，洞內只有一個小房間與一個箱子。圖中的多房間、床鋪、橋與家具不代表開局配置；介面數字與格子尺度不作為實作數值。這些圖片尚未拆成可用的圖集或動畫素材。
