## 初始供應與依賴檢查

地表有莓果、蘑菇、堅果共 18 食物；枝條共 8 木材，小型徒手軟木樹共 12 木材；纖維共 12。上述地點有穩定 ID，未放在水面。不是每日自動入帳，也不能無限點擊產出。

五個草窩與第二箱共需 8 木材、11 纖維。地表初始量足夠，不需要斧頭或工作台。睡眠區可先睡地板；初始食物可從行囊取用；種子與食物分帳；澆水從水邊徒手補水，此為避免工具依賴死結的暫定方案。M2–M3 實作時須加水邊可達與容量檢查，不能將資料試算視為完整生活鏈驗收。

工時上限：5×720×75%＝每日約 2700 泡泡秒；這只是容量上界，不能代表尋路／搬運已驗證。完整五日可玩性、運輸成本、即時倉儲峰值與錯誤路線在 M2–M4 驗證。

## 任務與教學資料字典

| 結構 | 關鍵欄位／規則 |
| --- | --- |
| 地格 | scene、x、y；地下 `x,y` 為鍵，floor 記錄已挖地面 |
| 資源點 | id、type、x、y、amount；amount 是有限可領取量 |
| 物品 | id、slots、edible；食物與種子分開 |
| 居民 | 穩定 id、可編輯名字預留、scene、x、y、color、accessory |
| 配方 | id、materials、workSeconds、footprint、blocks |
| 作物 | id、growthSeconds、foodYield、seedYield、seedCost、waterVisits |
| 原型標記 | id、type、目標或地格；只存本次記憶體，不假裝為可執行任務 |
| M2 任務目標模型 | id、target、requirements、progress、priority、claimant、reservation；待實作 |
| 任務狀態 | waiting → claimed → travelling → working → hauling → delivering → done；paused/cancelled/invalid |
| 教學 | 穩定 id、參考 day、conditions；條件式推進，不設日期截止 |

M2 必須把任務、需求帳、預約、隨機狀態與存檔版號一併序列化。M1 不建立不完整的自動存檔；重新載入會回到乾淨初始狀態，標記會清除。
