# M1 程式像素素材

本輪以 `src/render.js` 的本地 Canvas 像素塊繪製場景，沒有用概念圖裁切成假圖集。這批是供操作與辨識驗證的素材；手機視覺驗收後再決定擴充或替換。

| 素材 | 原生尺寸／尺度 | 腳底錨點 | 方向／動作 | 遮擋／佔地 |
| --- | --- | --- | --- | --- |
| 泡泡 | 畫布 32×36，身體約 24×24 | (16,30) | 正面，待機眨眼、跳行起伏、搬運箱、工作工具兩姿勢 | 不阻擋；一個色盤與至多一個配件 |
| 森林地格 | 菱形 38×20 | 中心 | 靜態 | 可走，水域預留為阻擋 |
| 地下地格 | 30×27 | 中心 | 靜態 | 15 格寬；土不可走，開挖地四向連通 |
| 大樹 | 約 70×90 | 底部中心 | 靜態 | 樹冠遮角色時淡化；裝飾不建立採集命中區 |
| 小軟木樹 | 大樹 0.75 倍 | 底部中心 | 靜態 | 可選取樹幹附近，冠部會依選中角色淡化 |
| 山洞 | 約 108×92 | 底部中心 | 靜態入口 | 獨立資產，含石階、苔蘚、暖燈；不等於已建家具 |
| 小箱 | 約 21×18 | 地格中心 | 靜態 | 1 格；開局唯一物件 |
| 採集物 | 約 24×24 | 地格中心 | 靜態 | 命中半徑至少 18 CSS px，附近候選提供按鈕 |

兩場景共用泡泡尺度，縮放作用於整個場景。畫布以約一半 CSS 尺寸渲染，再以 pixelated 放大；不依賴裝置像素密度。動作樣本以少量狀態快取，不每幀建立新圖集。

正面工作樣本不代表四向正式動畫已完成。M1 還需真人手機檢查角色大小、地表遮擋、重疊候選與觸控命中，通過後才批次製作各方向與進食／睡眠動作。
