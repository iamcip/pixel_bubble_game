## 本次驗證

- `npm test`：11 項通過。涵蓋開局、投影逆變換、四向連通、挖掘標記取消與不改資源、可達區域、材料供應、五日帳目、穩定 ID、相機邊界，靜態服務及路徑邊界，以及整個 UI 模組的 DOM／Canvas API smoke harness。
- UI smoke harness 實際載入 `main.js`，走兩場景渲染、居民選取／動作切換、挖掘標記與取消、拖曳／雙指縮放不誤標、20 隻樣本、暫停與倍速；使用替身 DOM／Canvas，不驗證真實瀏覽器排版與像素外觀。
- `npm run check`：核心模組 JavaScript 語法通過。
- 本地靜態服務：首頁、CSS、四個模組能以正確 MIME 回應。沒有外部網路執行依賴。

環境未提供 Chromium，官方 Playwright 瀏覽器下載返回無效壓縮檔；雲端瀏覽器無法連到本地服務。因此**沒有完成瀏覽器視覺截圖、手機實機、實際觸控、幀率測量**，也不宣稱已通過 M1 完整驗收。20 隻功能只是可使用的測試場景，不是效能結論。

## 已知限制

本版所有工作為標記預覽，不會挖開地面、搬運、採集、施工或增加庫存；上方食物數是固定開局總量。時鐘只預覽，不扣食物。兩場景目前沒有實際角色往返；正式五隻都留在地表。區域及標記僅本次頁面有效，重載清除；未實作本機存檔。五日收支是資料試算，不是五日遊戲測試。草窩、箱子配方與作物數字皆暫定。

## 下一步 M2

1. 先完成 M1 手機畫面／操作檢查，修正角色尺寸、命中及遮擋問題。
2. 建立與渲染分離的固定時鐘和四向尋路，入口連接兩場景。
3. 任務領取、有限資源／儲位預約、兩欄搬運、交付守恆，再加入取消及中斷恢復。
4. 接連續食物需求帳與錯開休息，驗證 1×／2× 資源消耗一致。
5. 版本化存檔覆蓋搬運中、施工中、進食中的重載；先驗證，再接 M3。

本次以原生 ES modules 驗證技術選擇，不鎖套件版本。M2 視型別與資料量需要決定 TypeScript。GitHub 上傳不等於公開發佈網站；此 repo 的私有權限維持不變。
