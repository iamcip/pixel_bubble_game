# 進擊的泡泡：美術素材交付指南

目標：以 `assets/concepts/slime-colony-concept-v2.png` 為風格參考，保留較簡化、易辨識的像素輪廓、柔和泡泡與暖光森林。現有 Canvas 形狀為互動原型；單調整色彩不等同正式美術。本指南列的是建議交付規格，尚未接入 PNG 素材載入器。

## 如何提供

可以直接在對話附 PNG、整包 ZIP、或提供可讀取的素材檔案連結。每一張圖請標明用途、哪一版是定稿；不必先做完整遊戲素材。只提供參考圖也可以，但參考圖和可直接使用的遊戲素材不同，仍需另做拆件與像素整理。

先做同一張風格樣板：一隻泡泡、一棵樹、一個洞口、一塊地面，拼在手機實際顯示比例上確認後，再製作全套。可以先交較大的原圖，由程式接入時一起確認比例；下面的數字不是必須一次做到的門檻。

## 建議分檔

| 分類／建議路徑 | 格式與建議原生尺寸 | 內容與限制 |
| --- | --- | --- |
| `backgrounds/forest-far.png` | 不透明 PNG，約 1024×1024 起 | 遠處森林、霧、柔光；可延伸或重複。不要畫入泡泡、可採集物、洞口、按鈕；背景不參與點選或阻擋。 |
| `residents/bubble-base.png` | 透明 PNG，每幀 64×72 | 共用身體，單幀先做待機；腳底錨點建議 (32,60)。預計顯示約 32×36 CSS px，可依手機樣板調整。 |
| `residents/accessory-sprout.png` 等 | 透明 PNG，64×72 | 與身體同畫布與錨點；葉芽、帽子、花朵各一張。五種色盤共用輪廓，每隻至多一個配件。 |
| `objects/cave-entrance.png` | 透明 PNG，建議 256×224 | 石頭、苔蘚、階梯、燈可整組繪入；洞口保持開放。底部中心錨點，另標洞口可點擊區；不要把地表角色畫進去。 |
| `objects/tree.png` | 透明 PNG，約 160×224 | 樹幹底部中心為錨點。最好另交樹幹與樹冠兩層，以便角色走後面時淡化樹冠；兩層同畫布。 |
| `objects/rock.png` | 透明 PNG，約 64×64 | 獨立岩石；佔格另外標註。 |
| `items/berry.png`、`mushroom.png`、`nut.png`、`branch.png`、`fiber.png` | 透明 PNG，48×48 起 | 每種物品一張、底部中心錨點，在手機上可辨識；不可混在背景裡。 |
| `furniture/chest.png` | 透明 PNG，64×64 起 | 小箱子，1 格。其它家具後續製作，開局不加床、桌子或農田。 |
| `tiles/surface-grass.png`、`surface-path.png`、`surface-water.png` | 透明 PNG，菱形有效區 76×40 | 對應現有地表 38×20 的 2 倍素材。草地、泥路、水分開；無黑縫，可拼接，先各 1 款。水岸另交邊緣素材。 |
| `tiles/underground-soil.png`、`underground-floor.png` | PNG，有效地格 60×54 | 對應現有地下 30×27 的 2 倍素材。土、開挖地板分開，紋理可連續拼接。 |
| `tiles/underground-wall-*.png` | 透明 PNG，與地下地格同尺度 | 土壁上／下／左／右、轉角可分檔；牆高可超出地格，但需註明錨點。後續整理為四向連接圖集。地下不能是一張固定的房間背景。 |
| `objects/underground-exit.png` | 透明 PNG，約 64×112 | 上方通往地表的亮口／指示牌，獨立點擊區。 |
| `ui/button-frame.png`、`panel-frame.png`、`icon-*.png` | 透明 PNG，按設計提供 | 木框、選取框和圖示；框邊可拉伸部分另標註。不要把文字畫死在圖片內。 |

這些尺寸採現有場景座標的約 2 倍素材作為起點，而非另一套遊戲格子大小；接入時須統一原生像素比例，避免不同素材的像素顆粒忽大忽小。家具的佔格與圖片尺寸分開定義。地表維持目前等角視角，地下維持正面平面，不混用透視。

## 通用交付要求

- 獨立物件使用真正透明背景 PNG，不能是白色底或畫進圖裡的棋盤格。邊界留 2–4 像素透明空間，避免切掉配件或動畫。
- 不用 JPEG；避免平滑縮放、模糊邊、抗鋸齒。放大採整數倍最近鄰；原圖像素顆粒須一致。
- 地面接觸陰影最好另交 `*-shadow.png`；洞口暖燈可包含在原圖，但擴散光暈最好另交 `*-glow.png`。
- 動畫每幀同畫布、同腳底位置。可先交逐幀 PNG，如 `bubble-idle-00.png`，之後再組圖集；不需要先把所有動畫畫在一張展示海報。
- 動作按需求補：待機、跳行、搬運、工作，其後吃飯、睡眠。每個方向與每幀都需保持身體、配件和手上物品的對齊。
- 建議附簡單說明：檔名、尺寸、腳底位置、佔幾格、方向、幀數／每秒幀數；不知道的可先由接入時一起決定。

## 建議第一批

先交 `bubble-base.png`、`tree.png`、`cave-entrance.png`、`surface-grass.png`。我會先接入同一個小場景，讓你在目前手機網址比較；確認後才擴到其它物件、地下地格與動畫。

完整「地表圖」和「地底圖」可作為構圖參考，但互動場景要保留可拆物件與地格，才能正確選取、遮擋、採集和挖掘。
