# 手機預覽與 GitHub Pages

`gh-pages` 分支只發布 index.html、styles.css、src/ 與 .nojekyll；不包含規格書、Word 文件或概念圖。

首次啟用：Repository Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: gh-pages / (root) → Save。

預期網址：https://iamcip.github.io/pixel_bubble_game/ 。只有 Pages 啟用且部署成功後才能開啟。手機直接用 Safari / Chrome 開啟，不需安裝 Node.js。

原 repo 保持 private；如果 GitHub 提示需升級方案，請勿自動改為公開 repo。Pages 網站通常公開可見。

此版本是 M1 操作預覽，尚未接入生活模擬與存檔。
