# 進擊的泡泡

五隻泡泡在微光森林發現空山洞，慢慢把它變成家。手機網頁像素風模擬經營遊戲。

目前已開始開發：**M0 資料基礎 + M1 雙場景互動原型**。這版可觀察泡泡、切換地表／地下、拖曳縮放、預覽採集與挖掘標記、指定區域；尚未接入自主派工、需求、施工或存檔，不是完整五日遊戲。

## 啟動

需要 Node.js 20 以上；無第三方執行依賴，不需 npm install。

```sh
npm start
```

開啟 `http://localhost:4173`。同 Wi-Fi 的手機可使用開發電腦的區域網路 IP 加 `:4173`。亦可用任意靜態伺服器託管本 repo；ES modules 不能直接以 `file://` 開啟。

```sh
npm test
npm run check
```

## 操作

- 地表／地下：上方頁籤，或直接點洞口／地下出口切換。
- 地圖：單指或滑鼠拖曳；雙指、滾輪或 +/− 縮放；⌖ 回到中心。
- 泡泡：點角色或下方名字，可試看待機、跳行、搬運、工作樣本。
- 資源：點一下直接標記採集／砍伐，顯示等待提示；再點一下取消，不會直接入帳。
- 地下：點泥土直接標記挖掘；睡眠／儲物區只能畫在可達空地。
- `?`：說明及 20 隻擁擠測試。新增角色是動作樣本，不改變正式人口。
- 鍵盤：場景聚焦後方向鍵平移，+/− 縮放，0 回中。

暫停與速度控制目前只影響預覽時鐘／動畫；背景暫停。工作標記與區域只在本次頁面有效，重載會清除。

## 技術與下一階段

原生 ES modules、Canvas 2D；資料、空間規則、渲染、輸入分離。M1 先用資料表與簡單 JavaScript 驗證，不引入套件或建置鏈；M2 再決定是否切換 TypeScript。所有視覺在本地以程式繪製，不依賴外部字型、圖片或 CDN。

下一步 M2：固定模擬步進 → 四向尋路與跨場景入口 → 領取／預約／搬運／交付 → 食物需求與休息 → 版本化存檔。手機實機驗收完成前，不把 M1 標記為通過完整驗收。

手機部署方式見 [GitHub Pages 設定](docs/github-pages.md)。`gh-pages` 已備妥靜態遊戲檔案；Pages 必須另行啟用並部署成功，才能直接用手機開啟。
